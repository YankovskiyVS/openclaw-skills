# Что переносится из выгрузки

Этот пакет предназначен для файлового хранилища OpenClaw 2026.7.1. Полные новые файлы истории проверяются до регистрации через SDK; установка плагина не требуется.

## Переписки

`conversations` — JSON-массив с `uuid`, `name`, датами, необязательной сводкой и `chat_messages`. У сообщения сохраняются UUID-идентичность, роль, текст, дата и `parent_message_uuid`. Корневые значения Claude распознаются отдельно; неизвестный реальный родитель или цикл дают ошибку. Запись идёт в порядке «родитель раньше потомка», с точным `parentId` в OpenClaw.

Один исходный чат становится одним обычным чатом OpenClaw, включая все ветки и независимые корни. Пустые чаты также сохраняются. Исходная выбранная ветка неизвестна: активной выбирается ветка с самым поздним конечным сообщением. Порядок записи сразу делает её активной; дополнительное переключение сессии не требуется.

Для `design_chats` используется отдельный формат: объект с `messages`, у которых `content` — вложенный объект. Берутся внешние UUID, роли и даты; внутренние различающиеся идентификаторы и времена остаются в исходнике. Вложения с типом `skill` становятся справочными файлами, не устанавливаются как навыки.

Повторяющиеся сообщения обычных чатов выбираются по времени обновления. Design-снимки объединяются с обновлением родительских связей и дат. Разные исходные версии остаются в полном архиве. Для уже записанного идентификатора SDK не позволяет незаметно заменить содержимое. Если пользователь изменил или продолжил импортированный чат, повторная полная проверка может остановиться; чужие новые сообщения не удаляются.

## Справочные материалы

Все материалы ниже находятся в отдельной области `memory/imports/claude-web/` рабочей папки выбранного агента. Имена назначения вычисляются из идентичности и содержимого; абсолютные пути исходной памяти никогда не используются как пути записи. Существующие изменённые файлы не перезаписываются.

| Источник | Представление в OpenClaw |
| --- | --- |
| `memories.conversations_memory` | Исторический справочный документ |
| `project_memories` | Отдельные документы с областью исходного проекта |
| `memory_files` | Отдельные Markdown-материалы с безопасными именами |
| `projects` | Карточки исходных проектов, описания и исходные инструкции как данные |
| `projects.docs[].content` | Полные тексты документов проектов |
| `attachments[].extracted_content` | Реально доступный текст вложений; одинаковое содержимое объединяется |
| `summary` переписок | Исторические сводки вне активной истории и механизмов сжатия |
| `frames` / `artifacts` | Каталоги, комментарии и тексты версий; HTML не выполняется |
| `feedback` / `reflections` | Исторические рефлексии, без применения как новых инструкций |

Каталог `catalog-<batch>.md` связывает все справочные материалы. Отдельный `memory-catalog-<batch>.md` содержит только общую память, память проектов и исходные файлы памяти. Компактный указатель в `MEMORY.md` делает этот слой заметным агенту. Факты не смешиваются с действующей памятью без указания происхождения, полные переписки в bootstrap не вставляются. Они доступны обычным файловым инструментам агента. `memory_get` и поиск зависят от разрешений и конфигурации памяти OpenClaw; семантическое индексирование может требовать настроенного провайдера. Импорт сам не вызывает модель или платную индексацию и не обещает готовность поиска без его проверки.

Проект OpenClaw требует настоящего Git-репозитория с коммитом. Для веб-проектов Claude не создаются фиктивные репозитории. Их содержимое переносится в справочные папки; чаты группируются в обычные группы `Claude — импорт` и `Claude Design`. Принадлежность обычных чатов проектам в изученной выгрузке отсутствует. Неизвестные ссылки дизайнерских чатов на проекты сохраняются в исходнике, не сопоставляются по названию.

## Что остаётся только в исходниках

- Скрытые рассуждения, старые вызовы инструментов и результаты, служебные вставки и бюджеты токенов не превращаются в инструкции и не загружаются текстовым дампом в модель. Обычный видимый текст сохраняется. Для полностью служебного сообщения остаётся короткая отметка с исходной ролью, датой и родительской связью.
- Аккаунт, создатели, настройки приватности и история входов — приватные исходные данные. Они не меняют аккаунт, разрешения или настройки целевого OpenClaw.
- Оригинальный HTML и все варианты сообщений сохраняются без изменений. Извлечение текста HTML не воспроизводит интерактивные приложения.
- Неизвестные будущие категории сохраняются целиком; отчёт явно отмечает отсутствие нативного преобразования.

Если `files` содержит только имя и UUID, это не бинарный файл. Блок изображения с `source: null` не позволяет восстановить изображение. Такие сведения сохраняются, но нативный предпросмотр отсутствующего файла не создаётся. Сетевые ссылки на внешние вложения отдельно не скачиваются.

## Хранение после очистки

В постоянном каталоге импорта `<importsDir>/<batch>/` остаются:

- `originals/<sha256>` — неизменённые байты всех переданных файлов, включая ZIP и необязательный манифест; исходные имена и хеши перечислены в `plan.json`;
- `source/` — нормализованные отдельные записи и сопутствующие файлы, включая приватные метаданные и оригинальные артефакты;
- `references/` — проверенная копия справочных материалов;
- `prepared/` — канонические порции для сверки и восстановления;
- `plan.json`, `receipt.json` — опись и состояние операции без полного текста чатов.

В рабочем каталоге остаются план, квитанция и технический журнал клиента. Исходная папка пользователя не удаляется. Очистка удаляет только созданные программой временные копии; постоянный архив не считается мусором.

Сверка проверяет обе копии источников, все справочные файлы и собственный блок навигации в `MEMORY.md`. Пользователь может дописывать другие разделы памяти: они не считаются изменением импортированного блока. Изменённый блок не заменяется. При `skipped_bootstrap_budget` материалы сохранены, но указатель не добавлен; это явно отражено в квитанции.
